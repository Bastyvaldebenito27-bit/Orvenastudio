# INSIDUS

Sitio de marca de INSIDUS — exportación de productos del mar.

## Estructura

Página única y autocontenida (`index.html`):

- **Intro 3D**: recorrido por scroll con seis actos (jibia, bacalao, pez espada,
  red, cadena de frío y cierre de marca). Escena WebGL; las fotos de producto se
  convierten en nubes de partículas en tiempo real.
- **Sitio**: navegación, Productos, Proceso, Mercados y Contacto, bajo la intro.

Disponible en 10 idiomas (es, en, fr, pt, it, de, zh-CN, zh-TW, ja, ko).

## Despliegue

Estático, sin build. `index.html` en la raíz.

## Pendiente

Los campos marcados como "Por completar" en la web esperan datos reales:
nombre científico, presentaciones y formatos de empaque de cada producto, y
correo, teléfono y dirección de contacto.
